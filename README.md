An interactive Software Delivery Operating System: a 10-stage delivery roadmap with gates, roles & RACI, communication guides, templates, and methodology notes.

Zoomable Mermaid diagrams for the full pipeline, defect lifecycle, and Git/CI flow — all in one self-contained page.

---

## What’s inside

| Section | What you get |
| :--- | :--- |
| **Roadmap** | Ten stages, each ending in a pass/fail gate |
| **Methodology** | Why Scrum is the backbone, with XP · Kanban · Lean layered in |
| **Roles & RACI** | Who owns what — click any role for the full mandate |
| **Communication** | What to ask, who to ask, when |
| **Templates** | Checklists and artifacts you can reuse |
| **Diagrams** | Pinch-to-zoom, drag-to-pan flowcharts |

---

## Quick start

```bash
# Open the app in your browser
open index.html
```

Or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

No build step. No dependencies. Just open and explore.
